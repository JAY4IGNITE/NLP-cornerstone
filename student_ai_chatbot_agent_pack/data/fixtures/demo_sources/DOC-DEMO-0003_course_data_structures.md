## Course Description / Subject Info
Data Structures covers arrays, linked lists, stacks, queues, trees, graphs,
hashing, and elementary algorithm analysis. It is a core second-year course.

## Course Objectives
- Introduce fundamental linear and non-linear data structures.
- Develop the ability to analyze time and space complexity.
- Build problem-solving skills using appropriate data structures.

## Course Outcomes
After completing DEMO-CS201, a student can:
1. Select suitable data structures for a given problem.
2. Implement and evaluate common data structures.
3. Analyze algorithmic complexity using asymptotic notation.
